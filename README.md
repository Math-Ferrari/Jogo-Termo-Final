# Jogo Termo

Atividade da disciplina de Usabilidade, Desenvolvimento Web, Mobile e Jogos Digitais.

O projeto é um jogo de adivinhar palavras, desenvolvido com HTML, CSS e JavaScript.

## Como jogar

O objetivo é descobrir a palavra sorteada em até 6 tentativas.

Após cada tentativa, as letras mudam de cor:

- **Verde:** letra certa no lugar certo.
- **Amarelo:** letra certa no lugar errado.
- **Cinza:** letra que não está na palavra.

O jogo possui 16 palavras diferentes, de 4 a 6 letras.

## Como executar

Baixe os arquivos do projeto e abra o `index.html` no navegador.

É possível jogar usando o teclado do computador ou o teclado na tela.

Para começar outro jogo, basta clicar em "Nova partida".
